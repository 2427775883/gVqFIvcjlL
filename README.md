# 项目简介

## 核心功能
- 数据清洗：处理缺失值、异常值
- 数据预处理：标准化处理
- 数据统计
- 数据可视化
- 研究结论：分析数据集来源为seaborn平台的taxi.csv

## 适用场景
- 研究城市发展和社会变迁
- 分析出租车行业运作情况
- 了解乘客出行习惯和费用结构

## 技术特点
- 使用Python进行数据分析和可视化
- 依赖pandas、numpy、matplotlib等库
- 数据集来源为seaborn平台的taxi.csv
